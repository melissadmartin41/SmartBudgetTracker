# SmartBudgetTracker

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

## Overview
SmartBudgetTracker is a sleek and user-friendly web application designed to help individuals monitor their expenses, set budgets, and gain insights into their spending habits. Built with modern technologies, it aims to simplify personal finance management through intuitive charts and easy-to-use interfaces.

## Features
- Add and categorize expenses with custom labels
- Set monthly budgets and track progress
- Interactive charts and spending analytics
- Export data as CSV or PDF reports
- Responsive design for desktop and mobile

## Tech Stack
- Frontend: React.js with Material-UI
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT

## Installation
1. Clone the repository:

   ```bash
   git clone https://github.com/melissadmartin41/SmartBudgetTracker.git
   cd SmartBudgetTracker
   ```

2. Install dependencies for backend and frontend:

   ```bash
   # Backend
   cd backend
   npm install

   # Frontend
   cd ../frontend
   npm install
   ```

3. Set up environment variables in `backend/.env` (e.g. MongoDB URI, JWT secret).

4. Run backend server:

   ```bash
   cd ../backend
   npm start
   ```

5. Run frontend development server:

   ```bash
   cd ../frontend
   npm start
   ```

## Usage
- Sign up or log in to your account.
- Add expenses with descriptions, amounts, and categories.
- Set monthly budgets and track your spending progress.
- View detailed analytics through interactive charts.
- Export your financial reports anytime.
